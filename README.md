# Reis & Santos Advocacia — Landing Page

Landing page institucional do escritório **Reis & Santos Advocacia** (Aparecida de Goiânia – GO), especializado em **Direito de Família e Sucessões**.

## Sobre

Site de página única, estático e responsivo, com foco em credibilidade, acolhimento e conversão (WhatsApp/Instagram). Comunicação humanizada e didática, em conformidade com o Código de Ética e Disciplina da OAB.

### Seções
- Hero com proposta de valor e CTA
- Números de confiança (experiência, atendimentos, avaliação)
- Áreas de atuação
- Situações em que ajudamos (público-alvo)
- Equipe (Dra. Beatris Carla · Dr. Paulo)
- Como funciona o atendimento
- Dúvidas frequentes (FAQ)
- CTA final + contato e localização

## Tecnologias
- HTML5 semântico
- CSS puro (design system com variáveis, responsivo mobile-first)
- JavaScript vanilla (reveal on scroll, contadores animados, menu mobile)

Sem dependências ou build. Basta abrir `index.html`.

## Rodar localmente
```bash
python -m http.server 4173
```
Depois acesse http://localhost:4173

## Personalizar antes de publicar
- Substituir o número do WhatsApp `5562000000000` (arquivo `index.html`) pelo número real.
- Ajustar o link do Instagram (`https://instagram.com`) para o perfil oficial.
- Conferir endereço e link do Google Maps.

## Publicar no GitHub Pages
Nas configurações do repositório → **Pages** → Branch `main` / pasta `/root`.
